SEOPulse — Privacy Policy

Last updated: May 18, 2026

Data Collection

SEOPulse does not collect, store, or transmit any personal data. All SEO analysis runs entirely in your browser using the Chrome Extension APIs.

What We Access

  • Current page DOM: Read temporarily to analyze SEO elements — title, meta tags, headings, images, structured data (JSON-LD), and link structure. This data never leaves your browser.
  • Tab URL: Used only to display the page URL within the audit report popup.

What We Do NOT Collect

  • No browsing history tracking
  • No user identification or fingerprinting
  • No analytics, telemetry, or crash reporting
  • No cookies or local storage beyond Chrome extension defaults
  • No data sent to any external server

Third-Party Services

SEOPulse operates entirely offline and does not use any third-party services, external APIs, analytics platforms, or advertising networks. No data is shared with any external party.

Data Storage

The extension uses Chrome's built-in chrome.storage.local solely for extension preference defaults. No user data or audit results are persisted beyond the current session.

Permissions Explained

Permission Purpose
activeTab Required to read the current page's DOM for SEO analysis — only activated when you click the extension icon.
scripting Required to inject the SEO audit script into the current page to extract metadata. No remote code is injected.

Data Removal

Uninstalling the extension removes all traces. Since no personal data is collected, there is no data to delete or export.

Children's Privacy

SEOPulse is not directed at children under 13 and does not knowingly collect any personal information from children.

Changes to This Policy

If this policy changes, we will update this page and note the revision date.
